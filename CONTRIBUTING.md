# Como contribuir

Obrigado pelo interesse em melhorar este portfólio. Correções de documentação, ajustes visuais, melhorias no modelo e novos projetos são bem-vindos.

## Antes de começar

1. Verifique se já existe uma issue sobre a mudança proposta.
2. Para alterações maiores, descreva primeiro o objetivo, a fonte de dados e o impacto esperado.
3. Nunca inclua credenciais, dados pessoais, tokens ou fontes sem permissão de redistribuição.

## Padrão para projetos

Cada projeto deve incluir:

- um arquivo `.pbix` funcional;
- as fontes necessárias ou instruções claras para obtê-las;
- um `README.md` com objetivo, escopo, fonte, instruções e limitações;
- um dicionário de dados quando a base tiver mais de uma tabela ou campos pouco evidentes;
- imagens e recursos visuais em uma pasta própria;
- nomes de arquivos descritivos e links relativos válidos.

## Enviando uma alteração

1. Crie uma branch com um nome curto e descritivo.
2. Faça alterações focadas e use mensagens de commit objetivas.
3. Confirme que o `.pbix` abre e que as consultas podem ser atualizadas.
4. Revise os links e a formatação dos arquivos Markdown.
5. Abra um pull request explicando o problema, a solução e como a mudança foi validada.

## Checklist do pull request

- [ ] O dashboard abre sem erro no Power BI Desktop.
- [ ] As fontes e o período dos dados estão documentados.
- [ ] Nenhum dado sensível ou credencial foi incluído.
- [ ] Os READMEs refletem o comportamento atual do relatório.
- [ ] Arquivos temporários e backups não foram adicionados.
